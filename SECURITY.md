# Security Policy

## Supported Versions

We take security seriously. The following versions are currently supported with
security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in qiskit-waveform-sim, please report
it responsibly:

1. **Do not** open a public GitHub issue for security vulnerabilities.
2. Email the details to: **pratul.deshpande06@gmail.com**
3. Include:
   - A description of the vulnerability
   - Steps to reproduce (if possible)
   - Potential impact assessment
   - Any suggested fixes or mitigations

## Response Timeline

- **Acknowledgment**: Within 48 hours
- **Initial Assessment**: Within 1 week
- **Fix Timeline**: Depends on severity, typically within 30 days for critical issues

## Disclosure Policy

- We will coordinate with you on the disclosure timeline
- We will credit you in the security advisory (unless you prefer anonymity)
- We will publish a security advisory after the fix is released

## Security Best Practices for Users

- Always install from PyPI: `pip install qiskit-waveform-sim`
- Verify package integrity: `pip install --require-hashes qiskit-waveform-sim`
- Keep dependencies updated: `pip install --upgrade qiskit-waveform-sim`
- Review the [CHANGELOG.md](CHANGELOG.md) for security-related updates
